### Task 1: Startup recovery

**Interfaces:**
- Produces: `def startup(deps: Deps) -> None` called by `main()` before the loop: (1) live mode → `broker.cancel_all()` + close every open `mirror_map` row with reason `restart`, (2) read `latest_risk_state()`; if HALT → log and refuse to trade (loop runs snapshot-only), (3) first cycle then re-mirrors the ladder from scratch (M1 Task 8 already makes this idempotent).

- [ ] **Step 1: Write the failing test**

```python
# tests/test_recovery.py
from src.main import Deps, startup
from src.store import Store
from src.models import RiskState
from unittest.mock import MagicMock

def test_startup_cancels_all_and_clears_mirror_map(tmp_path, cfg_live):
    st = Store(tmp_path / "t.db")
    st.mirror_put(1, 555, 57_860.0, 0.2, 0.0301, 0.1505, 1000)
    broker = MagicMock()
    deps = Deps(cfg=cfg_live, store=st, watcher=MagicMock(), broker=broker)
    startup(deps)
    broker.cancel_all.assert_called_once()
    assert st.mirror_get() == {}                      # stale mirror rows closed

def test_startup_respects_persisted_halt(tmp_path, cfg_live):
    st = Store(tmp_path / "t.db")
    st.record_event(1, "critical", "state_change", "HALT")
    deps = Deps(cfg=cfg_live, store=st, watcher=MagicMock(), broker=MagicMock())
    startup(deps)
    assert st.latest_risk_state() == RiskState.HALT.value   # still HALT, no reset
```
