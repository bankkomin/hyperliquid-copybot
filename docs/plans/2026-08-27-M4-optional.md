# M4 — Decision Record: Optional Features Not Built

**Status:** closed 2026-08-27. Nothing from the speculative list was built,
deliberately. PRD §13 gates M4 on *"only if M2/M3 economics justify it"*, and
none of the trigger conditions have fired.

## The gate, re-checked after M1–M3

| Item | Trigger | Fired? | Decision |
|---|---|---|---|
| Multi-leader support | A second leader worth copying is identified | No — one leader, and his economics are still unproven (PRD §14) | **Not built.** Adding a second before the first is validated multiplies unvalidated risk. |
| Remote dashboard (phone) | The localhost-only dashboard has concretely blocked a decision | No | **Not built.** Would need auth, TLS and an exposed port on the VPS — a real attack surface in front of a trading account, bought with zero evidence of need. |
| Playback / replay on the chart | Someone needed to replay history beyond what SQLite answers | No | **Not built.** Every cycle is already in `decisions`/`snapshots`; a SQL query answers the questions replay would. |
| EMA / SMA / Bollinger indicators | — | No | **Not built.** Indicators inform *your own* entries; this bot has no entries of its own to inform. |

## What M4 shipped instead

Two things that were genuinely missing for the product to be usable, both
uncovered by testing rather than invented:

1. **[README.md](../../README.md)** — the repo had none. A double-click
   deliverable is not deliverable without setup instructions, the risk model
   stated plainly, the un-HALT procedure, and the honest economics.
2. **Fresh-clone verification** of the standalone requirement, which found two
   real launcher defects:
   - `timeout` fails with *"Input redirection is not supported"* whenever stdin
     is redirected (scheduled tasks, piped runs) — replaced with `ping`-based
     waits throughout.
   - `pip` can report success while leaving an unusable tree (on a deep folder
     it dies with `WinError 206` part-way through). The launcher now proves the
     install by importing the dependencies, and prints the actual fix if not.
   - Dash's startup banner was polluting `copybot.jsonl`; the log handler now
     filters to JSON records only.
